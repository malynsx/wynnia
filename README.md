# Paddock

A Wynncraft mount breeding helper: stable manager, Wynntils item-string import, breeding simulator, lineage planner, feed planner, training calculator and reference almanac. Static site, no build step. Open `index.html` or serve the folder.

Game data comes from the Wynncraft Wiki (Mounts, Horses). The breeding bonus and variance are not documented, so they are adjustable and can be fitted from real breeds in the Ledger tab.

Fan-made; not affiliated with Wynncraft or Mojang.
